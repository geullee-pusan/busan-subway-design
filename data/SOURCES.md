# 데이터 출처

게임에 들어가는 숫자와 사실의 출처를 적는다. 역 수, 날짜, 비용, 인구 같은 사실은 이 문서에 적힌 출처에서만 가져온다(CLAUDE.md).

- 모든 원본은 **2026-09-22**에 받았다.
- 파일마다의 주소, 크기, SHA-256은 [`raw-lock.json`](raw-lock.json)에 있다. `npm run validate`가 해시를 대조한다.
- 받는 목록과 Overpass 쿼리는 [`scripts/sources.mjs`](../scripts/sources.mjs)에 있다. `npm run fetch`로 다시 받는다.
- 행정동 경계와 고도 타일은 크고 바뀌지 않는 판본이라 git에 넣지 않는다. 나머지 원본은 git에 넣는다.

- SRTM은 건물 높이가 조금 섞인 표면 높이다. 도심 칸의 경사가 실제보다 조금 크게 나올 수 있다.

## 4. 원본에서 찾은 문제와 고친 방법

1. **SPEC의 데이터셋 번호 두 개가 없어졌다.** 15043685(역사 정보)는 15043686 파일로, 15001019(운행 정보)는 3033564 파일로 바꿨다.
2. **3033564의 소요시간에는 정차시간이 없다.**
   - 더하면 시각표의 전 구간 시간보다 18~22% 짧다.
   - 그래서 표정속도(15142581)로 노선 평균 정차시간을 계산했다(3장).
3. **15137827(동해선 역 위치)에 틀린 행이 있다.**
   - 교대역 좌표가 서울 교대역이다.
   - 송정역 행은 광주송정역(역번호 2514)이다.
   - 부산원동역 좌표가 양산 원동역(경전선)이다.
   - 동래역은 1.6km, 센텀역은 1.2km, 북쪽 9개 역은 약 400m가 OSM과 다르다.
   - 거제해맞이역을 3호선 환승역으로 적었지만, 실제 환승역은 거제역이다.
   - 그래서 동해선 좌표는 OSM을 쓰고, 이 파일은 교차 확인에만 쓴다.
4. **OSM 동해선 노선에 부산원동역이 빠져 있다.** 역 노드는 있어서 안락과 재송 사이에 넣었다(`data/edits/stations.json`). 그래서 코레일 발표와 같은 23역이 된다.
5. **15043686의 환승 정보에 대저(3호선–부산김해경전철)가 없다.** 공식 노선도로 확인해 넣었다(`data/edits/transfers.json`).
6. **2021년 파일(15043686, 15050408)의 205번 역 이름은 "시립미술관"이다.** 2025년 파일(3033564)은 "벡스코"다. 화면 이름은 3033564를 따른다.

8. **개통일 출처가 서로 다르다.**
   - 1985-07-19 개통 구간을 부산교통공사는 "노포동~범내골"로, 위키백과는 "범어사~범내골"로 적는다(노포역은 1986-12-19 개통이라고 함). 게임은 공사 연혁을 따른다.
   - 1988-05-19 중앙~토성 개통은 위키백과에만 있다.
   - 부산김해경전철 개통일은 운영사 연혁이 2011-09-17, 위키백과가 2011-09-16이다. 게임은 운영사를 따른다.
   - 동해선 구간별 개통일은 공식 출처를 찾지 못해 위키백과를 따른다.
